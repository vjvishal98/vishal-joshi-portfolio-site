# Vishal Joshi — Portfolio Website

Responsive dark-themed portfolio for Python Developer / AI-ML Developer.

## Run locally
Open `index.html` in a modern browser. Keep the `assets` folder beside it.

## Included
- Contact details, About, Projects, Skills, Experience and Education
- Resume section embedded on the same page
- Dedicated Certifications section with certificate links
- Direct GitHub links for FER-Mental-Health-Detection, loan_Eligibility_Prediction, Covid_19_update_tracker and MedExplain AI
- Responsive mobile navigation

## Publish with GitHub Pages
Upload all files and the `assets` folder to the root of a public GitHub repository. Then open Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`, and save.
